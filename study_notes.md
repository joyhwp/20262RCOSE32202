## Process
A process is a program in execution.
## Thread
Threads share resources within a process.
## System Call
System calls provide an interface to kernel services.
## Scheduling
The scheduler selects which process runs next.
## Context Switching
The OS saves and restores execution context.
## Virtual Memory
Virtual memory provides each process with an address space.
