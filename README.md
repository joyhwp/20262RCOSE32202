# Operating Systems Study Notes

This repository contains my personal study notes for the Operating Systems course at Korea University.

## About This Repository

The purpose of this repository is to organize key operating system concepts and practice using Git and GitHub for version control.

## Topics Covered

- **Processes and Threads:** Process management, multithreading, and context switching
- **CPU Scheduling:** FCFS, SJF, Round Robin, and MLFQ
- **System Calls:** Communication between user space and kernel space
- **Memory Management:** Virtual memory and address spaces
- **Synchronization:** Mutexes and shared resources
- **Inter-Process Communication:** Pipes and shared memory

## Repository Structure

- `README.md` — Repository overview
- `study_notes.md` — Operating systems concepts and study notes

## Git Practice

This repository is also used to practice basic Git operations, including:

- Creating and modifying files
- Tracking changes
- Writing commit messages
- Maintaining version history
